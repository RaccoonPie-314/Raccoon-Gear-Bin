Flat layout of self-contained `<script setup lang="ts">` SFCs under `app/components/`, with a single `category/` sub-package that splits responsive variants (`CategoryDesktop.vue`, `CategoryMobile.vue`) behind a thin `CategoryNav.vue` facade which renders each via Tailwind breakpoint classes (`hidden lg:flex`). All components are stateless presentational shells: typed inputs via `defineProps` / `withDefaults`, events via `defineEmits`, two-way binding via `defineModel`. Cross-cutting concerns (i18n, dark mode) are consumed from Nuxt composables (`useI18n`, `useColorMode`) rather than passed as props. `SearchDock.vue` is the most complex component — it Teleports its launcher and overlay to `body`, measures DOM rects at morph time, locks window scroll during the dialog, and animates a pill-to-field transition using `requestAnimationFrame` + CSS transitions keyed by `TransitionEvent`. Global theming lives in `app/assets/css/main.css`, which imports Tailwind v4 and `@nuxt/ui`, defines the `Public Sans` font family in an `@theme static` block, and adds page-level animations plus select-morph keyframes targeting `[data-slot="content"][role="listbox"]` from Reka UI.
