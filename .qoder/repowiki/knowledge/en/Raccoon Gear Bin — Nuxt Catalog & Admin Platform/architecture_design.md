The root is a single Nuxt 4 application (`package.json` scripts `dev`/`build`/`generate`) whose `nuxt.config.ts` registers the four modules that glue the children together: `@nuxtjs/supabase` connects the frontend to the `supabase_backend` schema/RLS/storage; `@nuxtjs/i18n` (with `i18n.config.ts` declaring `en`/`km` messages) powers the bilingual UI consumed by both catalog and admin pages in `frontend_app`; `@nuxt/ui` + `@nuxtjs/color-mode` provide shared design tokens and dark/light switching. Runtime configuration splits secrets (`supabaseServiceRoleKey`, `NUXT_PUBLIC_SUPABASE_URL`, `NUXT_PUBLIC_SUPABASE_ANON_KEY`) from public values via Nuxt `runtimeConfig`. The Supabase cookie name `raccoon-admin-auth` and locale cookie key `raccoon-gear-bin-locale` are the cross-child contracts between the Nuxt app and the Supabase backend's auth/session layer.
