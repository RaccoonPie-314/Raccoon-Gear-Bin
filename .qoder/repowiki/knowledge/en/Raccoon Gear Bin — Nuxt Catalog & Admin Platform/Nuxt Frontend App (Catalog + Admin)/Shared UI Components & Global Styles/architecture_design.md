Flat layout of self-contained `<script setup lang="ts">` Vue SFCs under `app/components/`, with a single `category/` sub-package that splits responsive variants (`CategoryDesktop.vue`, `CategoryMobile.vue`) behind a thin `CategoryNav.vue` facade that conditionally renders each via Tailwind breakpoints. All components are stateless presentational shells: they receive data through typed `defineProps` / `withDefaults`, emit events via `defineEmits`, and use two-way binding through `defineModel`. Cross-cutting concerns (internationalization, dark mode) are consumed from Nuxt composables (`useI18n`, `useColorMode`) rather than passed as props. The `SearchDock` component is the most complex — it Teleports its launcher and overlay to `body`, measures DOM rects at morph time, locks window scroll during the dialog, and animates a pill-to-field transition using `requestAnimationFrame` + CSS transitions. Global theming lives in `app/assets/css/main.css`, which imports Tailwind v4 and `@nuxt/ui`, defines the `Public Sans` font family in an `@theme static` block, and adds page-level animations and select-morph keyframes.
